# IELTS Course

A clear IELTS study guide with English, Kazakh, and Russian interfaces. The app includes section guides, daily study plans, progress tracking, notes, bookmarks, and direct links to practice tests.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

Without an account, progress stays in the current browser. Google sign-in can sync a private course state through Supabase. See `supabase/SETUP.md` and `.env.example` for the cloud setup.
