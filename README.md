# IELTS Course

A clear IELTS study guide with English, Kazakh, and Russian interfaces. The app includes section guides, daily study plans, progress tracking, notes, bookmarks, and direct links to practice tests.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The app stores personal progress in the browser and needs no database or environment variables.
